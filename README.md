# SENIM — жастарға арналған қауіпсіз фриланс

**Сайт:** https://senim-eight.vercel.app

SENIM — 14–22 жастағы жастар өз білімімен қауіпсіз табыс таба алатын фриланс платформасы. Тапсырыс берушінің ақшасы алдын ала escrow-ға салынады, сондықтан жұмыс төлемсіз қалмайды. Әр тапсырма мен чат хабарламасын «Сенім сүзгісі» тексеріп, оффлайн «жұмыстарды», дроппер схемаларын және баланы WhatsApp-қа шақыру әрекеттерін тоқтатады. 14–17 жастағылар ата-ананың SMS келісімімен ғана тіркеледі. 4% салықты платформа өзі ұстап, мемлекетке аударады.

> Хакатон прототипі: SMS шлюзі, банк және сервер әлі қосылмаған.

## Мәселе

Жасөспірім онлайн табыс іздегенде, ең алдымен алаяқтарға тап болады: дроппер схемалары, «қоймаға келіп кет» деген оффлайн тапсырмалар, жұмыс тапсырылған соң төлемей кету.

## Не жұмыс істейді

| Бөлім | Не істейді | Файл |
|---|---|---|
| **Сенім сүзгісі** | Тапсырма мен чат мәтінін 6 санат бойынша талдап (оффлайн қауіп, платформадан тыс байланыс, тікелей төлем, дроппер, жеке шекараны бұзу, жасқа сай емес сала), қауіп ұпайын береді. Қазақша, орысша және «w h a t s a p p» сияқты бүркемеленген жазуды таниды. Чатта телефон, карта (Luhn тексерісімен), IBAN, сілтеме, email, ник автоматты жасырылады. | `js/security.js` |
| **Escrow калькуляторы** | Комиссия (10%) мен салықты (4%) есептейді, 14–17 жас үшін жинақ үлесін көрсетеді, айлық лимитті (300 АЕК) ескереді. | `js/escrow.js` |
| **Тіркелу** | Барлық өрістер тексеріледі. 14–17 жаста ата-ананың телефоны міндетті және 6 таңбалы OTP расталмайынша тіркелу аяқталмайды. Бизнес үшін БСН/ЖСН бақылау саны алгоритмімен тексеріледі. | `js/validators.js`, `js/app.js` |
| **Кабинет** | Тапсырмалар, escrow, AI-ментор чаты (сол сүзгі арқылы), салық журналы, PDF шот-фактура. | `dashboard.html`, `js/enterprise.js` |
| **PWA** | Телефонға орнатуға болады, офлайн ашылады. | `manifest.json`, `sw.js` |

## Заңдық негіздер

- **Салық — 4%.** 2026 жылғы ҚР Салық кодексі бойынша интернет-платформа арқылы жұмыс істейтін өзін-өзі жұмыспен қамтығандар табыстың 4%-ын төлейді, платформа салық агенті ретінде оны өзі ұстап қалады. Маслихат мөлшерлемені ±50% өзгерте алады — мөлшерлеме `js/escrow.js` ішіндегі `CONFIG.taxRate`-те.
- **Лимит** — айына 300 АЕК (2026: 4 325 ₸ × 300 = 1 297 500 ₸).
- **14–17 жас** — ҚР Еңбек кодексі: ата-ана келісімі, қысқартылған жұмыс уақыты (14–15 жас: аптасына 24 сағ, 16–17 жас: 36 сағ).
- Кәмелетке толмағанның табысы — өз меншігі, сондықтан төлем оның картасына түседі; ата-ана тек көреді.

> Прототип: SMS шлюзі, банк және сервер қосылмаған. OTP коды демо ретінде экранда көрсетіледі, кабинеттегі сандар демо деректер.

## Іске қосу

```bash
python3 -m http.server 8080      # немесе: npm run dev
# http://localhost:8080
```

Docker арқылы:

```bash
docker compose up --build        # http://localhost:8080
```

## Әзірлеу

```bash
npm install
npm run build:css   # Tailwind → css/tw.css (HTML/JS-те жаңа класс қоссаңыз)
npm test            # сүзгі, валидаторлар, escrow тесттері
```

## Құрылым

